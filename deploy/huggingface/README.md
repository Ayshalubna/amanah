# Amanah — Agentic AML & KYC Investigation Copilot

Live demo of [github.com/Ayshalubna/amanah](https://github.com/Ayshalubna/amanah).
An AI assistant that checks bank customers for money laundering and sanctions, in Arabic and English,
and explains every answer in plain language. A person approves every decision.

All customers, transactions and sanctions-list names in this demo are synthetic.
